## 🚀 Cara Update Kode & Redeploy

Bila Anda melakukan perubahan pada salah satu file template (misalnya teks harga, nomor telepon, atau styling):

### 1. Update ke GitHub
Buka terminal di folder project ini:
```powershell
cd "C:\Users\lenovo\Downloads\template"
git add .
git commit -m "update: perbarui konten template"
git push origin main
```

### 2. Update Live di Vercel
Jalankan perintah satu baris non-interaktif:
```powershell
vercel --prod --yes
```
*Perubahan langsung aktif di [https://template-silk-six.vercel.app](https://template-silk-six.vercel.app) dalam hitungan detik.*
